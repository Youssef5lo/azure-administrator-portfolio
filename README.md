# Azure Administrator Hands-on Portfolio

## Overview

This repository documents my hands-on journey toward becoming an
Azure Administrator and preparing for the Microsoft Azure Administrator
(AZ-104) certification.

The portfolio demonstrates practical Azure administration skills across
identity, governance, networking, compute, storage, data protection,
and monitoring.
